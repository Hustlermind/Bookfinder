# 📚 Book Finder App

A React-based web application to explore books using the [OpenLibrary API](https://openlibrary.org/developers/api). Users can search for books by **title**, **author**, **year**, or **subject**, and browse results in a clean, responsive card layout.


## 🚀 Features

- 🔍 Live search with filters (title, author, year, subject)
- 📖 Displays book cover, title, author, and publish year
- 🧭 Pagination support for large result sets
- 🎨 Responsive UI with interactive cards
- 📦 Powered by OpenLibrary's public API
